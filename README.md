# Human-AI Collaborative Pentesting
 
This project explores a new paradigm for web application penetration testing based on the collaboration between a **human penetration tester** and an **AI coding agent**.
 
The core idea is to keep the traditional penetration testing workflow while giving the AI agent access to the same context and traffic observed by the human tester. This shared context allows the AI to better understand the application's behavior and the tester's actions, while enabling the human to monitor, review, and refine the AI's tests through Burp Suite.
 
The system is built around three components:
 
1. **`AI Agent`**: Codex or Claude Code, running inside **VS Code** as the shared workspace (the same place where the tester writes PoCs/exploits and where the agent reads code, suggests payloads, and drives Burp through MCP)
2. **`Burp Suite`**: the central proxy and traffic interception layer
3. **`Web Browser`**: the human pentester's interface with the target application

Burp Suite acts as the bridge between the human and the AI. All HTTP traffic generated by both the browser and the AI agent passes through Burp, creating a shared view of the assessment.
This means that when the human explores the application, the AI can see the requests and responses generated during that activity. Likewise, when the AI performs reconnaissance or attempts an attack, the human can observe exactly what it is doing through Burp and, when useful, take a request into Repeater to inspect, modify, and continue testing it manually.
 
The key concept is therefore shared context: instead of the AI working in isolation and receiving individual requests or instructions, it continuously gains context from the pentester's actions while the pentester maintains visibility and control over the AI's activity. VS Code ties this together as the single environment where code, findings, and the AI conversation live side by side.
 
The goal is not to replace the pentester, but to create a workflow where human intuition and decision-making are combined with the AI's ability to continuously analyze context, generate tests, and explore attack hypotheses.
 
 
# Setup
 
VS Code + Claude Code + Burp Suite (via MCP)
 
```
VS Code (+ Claude Code)
  └── MCP ─── Burp Suite ──> app target
```
