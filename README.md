# Human-AI Collaborative Pentesting
 
This project explores a new paradigm for web application penetration testing based on the collaboration between a **human penetration tester** and an **AI coding agent**.
 
The core idea is to keep the traditional penetration testing workflow while giving the AI agent access to the same context and traffic observed by the human tester. This shared context allows the AI to better understand the application's behavior and the tester's actions, while enabling the human to monitor, review, and refine the AI's tests through Burp Suite.
 
The system is built around three components:
 
1. **`AI Agent`**: Claude Code running inside VS Code as the shared workspace
2. **`Burp Suite`**: The central proxy and traffic interception layer
3. **`Web Browser`**: The human pentester's interface with the target application

Burp Suite acts as the bridge between the human and the AI. All HTTP traffic generated by both the browser and the AI agent passes through Burp, creating a shared view of the assessment.
This means that when the human explores the application, the AI can see the requests and responses generated during that activity. Likewise, when the AI performs reconnaissance or attempts an attack, the human can observe exactly what it is doing through Burp and, when useful, take a request into Repeater to inspect, modify, and continue testing it manually.
 
The key concept is therefore shared context: instead of the AI working in isolation and receiving individual requests or instructions, it continuously gains context from the pentester's actions while the pentester maintains visibility and control over the AI's activity. VS Code ties this together as the single environment where code, findings, and the AI conversation live side by side.
 
The goal is not to replace the pentester, but to create a workflow where human intuition and decision-making are combined with the AI's ability to continuously analyze context, generate tests, and explore attack hypotheses.


# Structure

```
.
├── .claude/     Claude Code skills (custom, reusable workflows defined for this project)
├── code/        Application source code (whitebox)
├── files/       Any file produced during the engagement (by Claude or by you, e.g. exploits, payloads, scripts)
├── result/      Claude's output (findings, reports, and skill results)
├── CLAUDE.md    Project context Claude reads automatically (scope definition)

```

```
VS Code + Claude Code
        └── Burp Suite (via MCP)

```


## Requirements
 
- [VS Code](https://code.visualstudio.com/download)
- [Claude Code extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code) for VS Code
- [Account Claude Pro](https://claude.ai) + CVP ([Cyber Verification Program](https://support.claude.com/en/articles/14604842-cyber-verification-program))
- [Burp Suite](https://portswigger.net/burp/downloads) (Community or Pro)
- [Java JDK](https://adoptium.net/temurin/releases)


## Setup

This setup should be performed only once at the beginning.

1. Install [VS Code](https://code.visualstudio.com/download).
```bash
wget -O code.deb 'https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64'
sudo apt install ./code.deb
```
2. Install [Claude Code extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code). <br>
   Login to your Claude Code account in VS Code and make sure you have the PRO version. <br>
   Also, for the best experience, it's best to have the [CVP](https://support.claude.com/en/articles/14604842-cyber-verification-program).
```bash
code --install-extension anthropic.claude-code
```
3. Install [Claude Code CLI](https://code.claude.com/docs/en/setup#install-claude-code)
```bash
curl -fsSL https://claude.ai/install.sh | bash
# winget install --id Anthropic.ClaudeCode   (<- Windows)
```
4. Install [Burp Suite](https://portswigger.net/burp/downloads) (Community or Pro)
```bash
wget -O burp_install.sh 'https://portswigger.net/burp/releases/download?product=desktop&type=Linux'
chmod +x burp_install.sh
./burp_install.sh
```
5. Install the official [MCP extension for Burp Suite](https://github.com/portswigger/mcp-server)
   1. `Extensions` tab in Burp Suite -> `BApp Store` -> Search `MCP Server` -> Install
   2. `MCP` tab in Burp Suite -> check `Enabled` (default: `http://127.0.0.1:9876`) - `Extract server proxy jar` and store it in a safe and fixed place.
6. Install [Java JDK](https://adoptium.net/temurin/releases)
```bash
sudo apt install default-jre
winget install EclipseAdoptium.Temurin.21.JDK   (<- Windows)
```
7. Connect Claude Code to Burp
```bash
claude mcp add burp --scope user -- java -jar "/<PATH>/mcp-proxy.jar" --sse-url http://127.0.0.1:9876/sse
claude mcp list
```
> After completing setup, restart your terminal, VS Code, and the Claude Code session so all changes take effect. <br>
> Keep Burp Suite open with the MCP tab enabled whenever you use it with Claude Code.


## Start

This setup should be performed every time you start a new project/engagement.

1. Open Burp Suite. <br>
   Make sure the `MCP` tab is still `Enabled` (configured during initial setup).
2. Set the target scope in Burp Suite.
   1. `Target` tab -> `Scope` -> `Add` (you can use `Use advanced scope control`)
   2. Enter the engagement's target URL/domain
3. Clone the project repository and open VS Code.
```bash
git clone https://github.com/IvAlexEv/AI-Assistant
code AI-Assistant
```
4. Set the target in `CLAUDE.md`, so Claude Code has the engagement context.
> Make sure the target you set in Burp Suite's scope matches the one in `CLAUDE.md`. <br>
> You can view the requests made by claude code in the `Logger` tab of Burp Suite.

## Disclaimer

- **Confidential data** <br>
If the target app's source code is proprietary to the client, check the engagement's confidentiality clauses before sharing it with Claude.
- **Burp history** <br>
Claude can read the HTTP history in Burp Suite. Avoid sending unnecessary sensitive data (e.g. credentials) through Burp during the engagement.
